# Проверка анимации в браузере

`animation.html` запускает настоящий скрипт и Canvas, без подмены отрисовки или часов. Он проверяет переключение кнопки, сохранение кадра при паузе и возобновлении, отсутствие изменений на паузе и заметность движения за 1,2 секунды.

После запуска `python -m tools.site_builder serve` подготовьте тестовую страницу из корня проекта:

```powershell
New-Item -ItemType Directory -Path .build/site/browser-tests -Force | Out-Null
Copy-Item tests/browser/animation.html .build/site/browser-tests/animation.html
```

Linux/macOS:

```sh
mkdir -p .build/site/browser-tests
cp tests/browser/animation.html .build/site/browser-tests/animation.html
```

Откройте <http://127.0.0.1:8000/personal-blog/browser-tests/animation.html> и оставьте вкладку активной на три секунды. Для теста нужна область просмотра не меньше 760×760 px, чтобы Canvas оставался видимым. Под изображением появятся результаты PASS/FAIL.

Проверка заметности требует, чтобы за 1,2 секунды минимум 0,2% пикселей изменились с разницей хотя бы 12/255 в одном из каналов RGB. Это порог заметного движения, а не сравнение с эталонным снимком; визуальную оценку главной он не заменяет. Отключение движения в системе учитывается на сайте; тест явно запускает анимацию нажатием кнопки.

Тестовая страница хранится вне публичного содержимого. Следующая чистая сборка удаляет её копию из `.build/site/`.
