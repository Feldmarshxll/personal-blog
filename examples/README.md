# Примеры материалов

Файлы в этом каталоге служат образцами и не публикуются на сайте.

Название страницы берётся из поля `title` во front matter. Основной текст начинайте с вводного абзаца или раздела второго уровня `##`; заголовок первого уровня `#` добавлять не нужно.

Для новой статьи скопируйте `article.md` в `content/articles/`, задайте уникальный `slug`, заполните метаданные и текст, затем смените `draft` на `false`. Рубрика должна совпадать с одним из идентификаторов в `content/site.yml`. Поля `series` и `series_order` добавляйте только для статьи, входящей в объявленную серию.

Для нового проекта скопируйте `project.md` в `content/projects/`, задайте уникальный `slug`, заполните описание и разделы кейса. Обновите `status`, список `technologies` и `featured` в соответствии с фактическим состоянием проекта.

Не публикуйте примерные названия, даты, результаты и контактные данные как реальные сведения.
